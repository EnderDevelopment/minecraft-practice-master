# PracticeMaster

PracticeMaster is a comprehensive Minecraft plugin designed to enhance your server's practice environment. It includes features like kit management, queue systems, party creation, duel systems, leaderboards, events, cosmetics, spawn selection, permissions, and a robust configuration system. This plugin is perfect for servers looking to provide a rich, engaging practice experience for their players.

## Install

1. Download the latest release from the GitHub repository.
2. Place the downloaded JAR file into your server's `plugins` folder.
3. Restart your server to load the plugin.

## Use

1. **Kit Management**:
   - Create and manage kits with configurable items, armor, and effects using the `/kit` command.
   - Save kit names, items, armor, effects, and settings to persistent files.

2. **Queue System**:
   - Implement a queue system for unranked and ranked matches using the `/queue` command.
   - Players can join queues using the items in their hotbar.
   - Use configurable messages for queue join, leave, and match start.

3. **Party System**:
   - Create and manage parties with commands like `/party create`, `/party invite`, `/party leave`, `/party kick`, `/party accept`, `/party deny`, `/party list`, and `/party info`.
   - Use aliases `/p` and `/party` for convenience.

4. **Duel System**:
   - Challenge other players to duels using the `/duel` command.
   - Accept or deny duel requests with `/duel accept` and `/duel deny`.

5. **Leaderboard System**:
   - View and manage leaderboards with the `/leaderboard` command.
   - Use aliases `/lb` and `/leaderboard` for convenience.

6. **Event System**:
   - Create and manage events with commands like `/event create`, `/event delete`, `/event list`, `/event info`, `/event start`, and `/event stop`.
   - Use aliases `/events` and `/event` for convenience.

7. **Cosmetics System**:
   - Manage and apply cosmetics with the `/cosmetics` command.
   - Use aliases `/cosm` and `/cosmetics` for convenience.

8. **Spawn Selector**:
   - Set and manage spawn points with commands like `/spawn set`, `/spawn list`, and `/spawn teleport`.
   - Use aliases `/spawns` and `/spawn` for convenience.

9. **Permissions**:
   - Control access to commands and features using a permissions plugin like LuckPerms or PermissionsEx.

10. **Configuration**:
    - Customize all plugin settings through the `config.yml` file and other relevant files.
    - Options include practice world name, practice items, arena settings, kit settings, queue settings, party settings, duel settings, leaderboard settings, event settings, cosmetics settings, spawn settings, and permissions settings.

11. **Messages**:
    - Customize all plugin messages to fit your server's needs.
